# Code Availability

The analysis code, tests, configuration files, and provenance relevant to this study are publicly available at:

- GitHub: https://github.com/wzwmm2006/ecg-lead-information-omi
- Zenodo concept DOI: `10.5281/zenodo.22046832`
- Zenodo v1.0.0 DOI: `10.5281/zenodo.22046833`

Version 1.1.0 adds readable and executable verification for the A1/A2a calibration analyses, P3 matched-TPR analysis, 100/250-Hz sensitivity analyses, and revised figure and table generation. The publication record for v1.1.0 is kept in the project release records and must include the exact version DOI and Git tag SHA.

The package does not include patient data, ECG waveforms, model checkpoints, hidden labels, or row-level predictions. Data accessions are listed in `docs/data_access.md`. Citation metadata are in `CITATION.cff` and `.zenodo.json`.
