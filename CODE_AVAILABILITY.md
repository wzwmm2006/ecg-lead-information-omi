# Code Availability Statement

The analysis code used for preprocessing, model training, evaluation, statistical inference, and figure generation is publicly available in a version-controlled repository and archived on Zenodo at https://doi.org/10.5281/zenodo.22046832. Source waveform data and hidden test labels are not redistributed. The acute coronary syndrome ECG dataset and STAFF III Database remain controlled by the original data providers and must be obtained according to their policies.
