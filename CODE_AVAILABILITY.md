# Code Availability

The analysis code, tests, configuration files, and provenance relevant to this study are available through the following repository and archival identifiers:

- GitHub: https://github.com/wzwmm2006/ecg-lead-information-omi
- Zenodo concept DOI: `10.5281/zenodo.22046832`
- Zenodo v1.1.1 DOI: `10.5281/zenodo.24132879`
- Zenodo v1.1.1 record: https://zenodo.org/records/24132879
- Zenodo v1.1.0 DOI: `10.5281/zenodo.24126410`
- Zenodo v1.0.0 DOI: `10.5281/zenodo.22046833`

GitHub tag `v1.1.1` and Zenodo record `24132879` identify the current source archive. Version 1.1.1 corrects the public P3 patient-cluster bootstrap helper and updates release metadata. Version 1.1.0 remains available under `10.5281/zenodo.24126410`, and version 1.0.0 remains available under `10.5281/zenodo.22046833`.

The package does not include patient data, ECG waveforms, model checkpoints, hidden labels, or row-level predictions. Data accessions are listed in `docs/data_access.md`. Citation metadata are in `CITATION.cff` and `.zenodo.json`.
