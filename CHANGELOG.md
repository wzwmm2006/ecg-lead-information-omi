# Changelog

All notable changes to this reproducibility package are documented here.

## 1.0.0 - 2026-08-21

- Initial public release prepared for the Scientific Reports submission.
- Preserved the frozen preprocessing, CNN, training, threshold, bootstrap, and STAFF III analysis specifications.
- Added configuration-driven commands, environment files, data-access documentation, provenance generation, and data-free dry runs.
- Excluded source data, patient-level artifacts, hidden labels, trained checkpoints, and private evaluator materials.
